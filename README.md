# Smart Lane Guard System

An AI-powered lane departure detection system built with Python, YOLOv8, OpenCV, and computer vision. The system monitors vehicle lane position in real time and provides visual, audio, and alert notifications when unsafe lane departures are detected.

## Features

- Real-time lane departure detection
- YOLOv8-based object detection
- Audio warning alerts
- Lane departure snapshots
- HTML map visualization
- Configurable settings using JSON
- Supports video file input

## Technologies Used

- Python
- OpenCV
- YOLOv8
- Ultralytics
- NumPy
- HTML
- JSON

## How to Run

1. Clone the repository

```bash
git clone https://github.com/anildamaidev/smart-lane-guard-system.git
```

2. Go to the project folder

```bash
cd smart-lane-guard-system
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the project

```bash
python smart_lane_object_detection.py
```
